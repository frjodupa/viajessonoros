# Flujo de trabajo

1. Leer primero `PROJECT_BRIEF.md`, `AI_RULES.md`, `AGENT_WORKFLOW.md` y `PROJECT_CHECKLIST.md`.
2. Revisar únicamente los archivos afectados por la tarea.
3. Aplicar el cambio mínimo necesario, sin refactorizaciones ajenas.
4. Ejecutar `npm run build`.
5. Si el build falla, corregirlo y no hacer push.
6. Si funciona, ejecutar `git add .`, crear un commit breve y ejecutar `git push origin main`.
7. Verificar el despliegue automático de Vercel y las rutas afectadas.
8. Responder con un resumen mínimo de archivos, build, commit, push y despliegue.
